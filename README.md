# DriveNG

Симулятор реалистичных разрушений автомобилей на **Godot 4.7** (физика Jolt).
Всё — машины, карты, звук — генерируется процедурно, внешних ассетов нет.

## Запуск

1. Установите [Godot 4.7](https://godotengine.org/download) (обычная версия, не .NET).
2. Откройте папку проекта в Godot (Import → `project.godot`) и нажмите F5.

## Сборка

- **Windows/Linux:** Проект → Экспорт → добавить пресет → Экспортировать (нужны шаблоны экспорта).
- **Android:** установить Android SDK/JDK по [инструкции Godot](https://docs.godotengine.org/ru/4.x/tutorials/export/exporting_for_android.html);
  на телефонах автоматически используется лёгкий рендер (OpenGL ES 3) и сенсорное управление.

## Что есть

- 22 машины на основе реальных прототипов (ВАЗ, ГАЗ, УАЗ, КАМАЗ, ЛиАЗ, BMW, Porsche, Toyota, Ford, Tesla…).
- Повреждения по delta‑V: вмятины на всех панелях, смятие кузова меняет коллизию, отрыв бамперов/дверей/капота/колёс,
  разбитые стёкла и фары, поломка двигателя, радиатора, подвески, пробитые колёса, пожар.
- 5 карт: краш‑полигон (с режимом краш‑теста), город со светофорами, шоссе, горный перевал, дерби‑арена.
- ИИ‑трафик, боты дерби, спавн машин «лоб в лоб», замедление времени.
- Пресеты графики от «Очень низкое» до «Ультра», авто‑разрешение для удержания FPS.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз, задний ход | W / S | триггеры |
| Руль | A / D | левый стик |
| Ручник | Пробел | A |
| На колёса / ремонт | R / Backspace | Y / D‑pad ↓ |
| Камера | C | Back |
| Замедление времени | T | X |
| Заспавнить машину | B | — |
| Пауза | Esc | Start |
